# AstrBot 多棋盘对弈插件

这是对旧版 `astrbot_plugin_chess` 的完整重写，新插件标识为 `astrbot_plugin_boardgames`。核心已经拆分为房间、规则引擎、渲染、持久化和 AstrBot 适配层。

## 支持棋种

- 国际象棋：完整规则由 `python-chess` 提供，支持 SAN 和 UCI。
- 围棋：默认标准 19×19，并可选择 9×9 或 13×13；支持提子、禁入点、全局同形、停一手和简化中国数子。
- 中国象棋：将军/送将校验、蹩马腿、塞象眼、炮架、九宫与将帅照面；支持常见中文记谱和 ICCS 坐标。
- 五子棋：13/15/19 路自由规则或标准五连；15 路连珠禁手；可独立启用 Swap2 平衡开局。
- 井字棋：3×3 完整规则。
- 黑白棋：完整夹子、自动跳过无子可下的一方和终局计子。

## 安装

在 AstrBot WebUI 的插件管理中上传本插件 ZIP。新版要求 AstrBot `>=4.9.2,<5`，依赖会通过 `requirements.txt` 安装。

若从旧版覆盖升级，建议先在旧棋局结束后再更新。2.4.2 起，长期数据主文件位于 `data/plugin_data/astrbot_plugin_boardgames/state.json`，旁边保留上一版 `state.json.bak`；AstrBot 插件 KV 仅作为兼容镜像。

首次启动 2.4.2 会自动尝试导入当前 `astrbot_plugin_boardgames` KV、改名前的 `astrbot_plugin_chess` KV，以及仍可找到的原版 `chess_stats.json`。每个来源只迁移一次，旧数据不会被删除。若旧版本因缺少更新源而必须删除后重装，请在卸载时**取消勾选**“同时删除插件持久化数据”；勾选该项会同时删除 `plugin_data` 和插件 KV。

从 2.4.1 起，`metadata.yaml` 已声明本 GitHub 仓库；仓库中的修复合入默认分支后，可直接使用 WebUI 的“更新”功能。

## 快速上手

```text
/开局 国际象棋             # 默认 15+10
/开局 国际象棋 计时=30+0   # 自定义：30分钟包干
/开局 围棋          # 默认标准 19 路
/开局 围棋 13路     # 也可选 9 路或 13 路
/开局 围棋 计时=60|3x30
/开局 中国象棋
/开局 五子棋 自由 15路
/开局 五子棋 标准 15路
/开局 五子棋 连珠
/开局 五子棋 连珠 Swap2
/开局 井字棋
/开局 黑白棋
/加入棋局
/选先
/选后
```

第二位玩家加入后，普通对局不会立刻开始。任一选手使用 `/选先`、`/选后`，或棋种对应的 `/选黑`、`/选白`、`/选红`，对手会自动分配到另一方并启动棋钟。五子棋 Swap2 使用其自身的强制选色流程。

正式开钟时会先发送独立对阵卡，展示双方头像（无法获取时显示昵称首字）、等级分、总战绩、该棋种战绩、双方历史交手、棋种规则和比赛用时；随后发送棋盘和计时规则文字。终局会发送结果卡，展示胜负、头像与双方等级分变化。

轮到自己时，可以任选一种写法：

```text
/下棋 Nc3
/Nc3
Nc3
/b1c3
/b1 c3
b1 c3
```

裸走法只在以下条件全部满足时触发：本群已有棋局、发送者是本局选手、正轮到该玩家、文本看起来像该棋种走法。其余管理指令仍必须带 `/`。

各棋种示例：

```text
国际象棋  Nc3 / b1c3 / O-O
围棋      D4 / pass（字母坐标跳过 I）
中国象棋  炮二平五 / h2e2 / h2 e2
五子棋    H8
井字棋    5 / B2
黑白棋    D3
```

## 对局指令

```text
/棋盘              重新发送纯图片棋盘
/棋谱              查看当前文字棋谱
/棋钟              查看双方精确剩余用时
/计时规则          查看计时格式、默认值和提醒策略
/悔棋              发起悔棋请求
/同意悔棋 /拒绝悔棋
/和棋              发起和棋提议
/同意和棋 /拒绝和棋
/流局              无人加入的空房任何人可取消；对弈中需双方同意
/同意流局 /拒绝流局
/强制流局          管理员清理卡住的棋局
/认输
/强制胜利          仅关闭比赛棋钟时使用旧式单步超时；有棋钟时自动判负
/AI分析            申请一次本地轻量分析
/势力范围          围棋势力图（同样需要对手同意）
/同意AI /拒绝AI
/选先 /选后 /选白 /选黑 /选红   任一选手选边，对手自动分配另一方
/交换 /加两子                    Swap2 开局阶段使用
/战绩              胜和负、总局数和 Elo 等级分
/对局记录 [@玩家] [棋种]   汇总胜和负、胜率、分棋种战绩及最近十局
/排行榜 [棋种]     分棋种等级分榜
/围棋计分          说明规则数子、AI 估分和和棋的区别
/棋类帮助 /下棋帮助
/国际象棋帮助 /围棋帮助 /中国象棋帮助 /五子棋帮助 /井字棋帮助 /黑白棋帮助
```

凡是发送棋盘图片的响应，消息链里只有图片组件；终局结果会作为下一条独立文字消息发送。棋盘用橙色标记上一步起点、绿色标记终点（落子类游戏只有终点）。所有棋盘上、下、左、右四边都有坐标，并在每手结束后自动翻成当前行棋方朝向。

## 比赛棋钟

棋钟在任一选手完成选边、对手自动分配另一方后启动，显示在每张棋盘图片顶部，用尽后自动判负。开局时可方便地覆盖：

```text
/开局 国际象棋 计时=15+10  # 每方15分钟，每步加10秒
/开局 围棋 计时=60|3x30    # 每方60分钟，随后3次30秒读秒
/开局 黑白棋 计时=10       # 每方10分钟包干
/开局 五子棋 不计时
```

默认值为：国际象棋 `15+10`、围棋 `60|3x30`、中国象棋 `10+5`、五子棋 `20+3`、井字棋 `2+2`、黑白棋 `10`。围棋使用世界业余比赛常见的标准基本用时与读秒，不再为群聊缩短；管理员仍可在 AstrBot WebUI 中逐棋种修改。

参考赛制包括 FIDE 常用的 `15+10` 快棋、世界业余围棋的 `60 分钟 + 3×30 秒` 读秒、中国象棋业余赛事的 `10+5`，以及国际五子棋赛事中的 `20+3`。

默认提醒为：全程每分钟，剩余 3 分钟内每 30 秒、2 分钟内每 15 秒、1 分钟内每 10 秒、30 秒内每 5 秒。WebUI 的 `clock_reminder_schedule` 可用 `阈值秒:间隔秒` 自定义，例如默认值 `86400:60,180:30,120:15,60:10,30:5`。

## 局势分析

`/AI分析` 每次都需要对手明确同意。所有六个棋种都会返回双方胜率与下一步推荐，不只支持国际象棋：

- 国际象棋、中国象棋：一层子力、机动性与将军启发式搜索。
- 围棋：轻量势力/面积估算、胜率、推荐着点，并追加一条独立的纯图片势力范围图；`/势力范围` 是同一分析请求的别名。
- 五子棋：按本局所选规则检查一步制胜、迫近成五和攻防热点。
- 井字棋：完整极小化极大搜索。
- 黑白棋：角、边、翻子数和当前子数的启发式评估。

分析完全在本地运行，不调用 LLM，也不产生模型费用；它适合娱乐提示，不等同于 Stockfish、KataGo 等专业引擎。围棋势力图是估算图，并不自动完成复杂死活判断。

围棋双方连续 `pass` 后的终局结果则不是 AI 估算：插件按面积法计算棋盘上的子和单方围住的空点，再为白方加入贴目。只有两边最终分数完全相等才是和棋；默认 6.5 贴目下一般不会出现完全相等。自动数子不会识别争议死子，终局前需先提净。

## 五子棋规则

规则与开局平衡可以分别选择：

```text
/开局 五子棋 自由            # 五子或以上即胜，无禁手
/开局 五子棋 标准            # 必须恰好五子，长连不算胜也不算犯规
/开局 五子棋 连珠            # 15路；黑方禁长连、四四和三三，白方五子或以上胜
/开局 五子棋 自由 Swap2      # 无禁手 + 国际 Gomoku 常用平衡开局
/开局 五子棋 连珠 Swap2      # 连珠禁手 + Swap2，可自由组合
```

Swap2 流程：开局者连续摆黑、白、黑三子；后加入者使用 `/选白`、`/交换` 或 `/加两子`。若选择加两子，则再连续摆白、黑两子，最后由开局者使用 `/选黑` 或 `/选白`。选色导致的换边由插件自动完成，之后白方正常行棋。

## 已知边界

- 围棋终局采用简化面积数子，不自动识别死子；正式对局应先自行提净死子。
- 中国象棋中文记谱支持常见的“炮二平五”形式；同路同名棋子需要区分前后时，请使用无歧义坐标记谱。
- 连珠禁手按 RIF 定义检测长连、四四、三三，并对常见“假三”进行递归合法性排除；极端复合题型仍建议以正式裁判结论为准。
- 活跃棋局和战绩保存在 `data/plugin_data/astrbot_plugin_boardgames/state.json`，写入时原子替换并保留一份 `.bak`；KV 仅作兼容镜像。更新插件目录不会触碰该文件。

## 目录

```text
main.py                    AstrBot 事件与指令适配
boardgames/session.py      房间、玩家和并发锁
boardgames/storage.py      plugin_data 状态文件、备份与旧数据迁移
boardgames/clock.py        加秒、包干、围棋读秒和分级提醒
boardgames/*_engine.py     各棋种规则
boardgames/render.py       统一图片渲染
_conf_schema.json          WebUI 配置
tests/                     不依赖 AstrBot 的规则回归测试
```

开发接口依据 [AstrBot 官方插件开发文档](https://docs.astrbot.app/dev/star/plugin-new.html)；长期数据遵循官方规范存放于 `data/plugin_data/{plugin_name}/`，图片通过单图片消息链发送。连珠禁手依据 [RIF 国际连珠规则](https://www.renju.net/rifrules/)，Swap2 流程依据 [RIF/RenjuNet 的 Gomoku Swap2 规则](https://www.renju.net/rule/11/)。棋钟预设参考 [FIDE 快棋规则](https://handbook.fide.com/chapter/e012023)、[世界业余围棋规则](https://www.nihonkiin.or.jp/event/amakisen/worldama/34/e/rules.html)、[中国象棋业余赛事规程](https://www.sport.gov.cn/qpzx/n5387/c29676858/content.html) 和 [RenjuNet 五子棋赛事用时](https://www.renju.net/tournament/3521/)。
