# AstrBot 多棋盘对弈插件

这是对旧版 `astrbot_plugin_chess` 的完整重写，新插件标识为 `astrbot_plugin_boardgames`。核心已经拆分为房间、规则引擎、渲染、持久化和 AstrBot 适配层。

## 支持棋种

- 国际象棋：完整规则由 `python-chess` 提供，支持 SAN 和 UCI。
- 围棋：默认标准 19×19，并可选择 9×9 或 13×13；支持提子、禁入点、全局同形、停一手和简化中国数子。
- 中国象棋：将军/送将校验、蹩马腿、塞象眼、炮架、九宫与将帅照面；支持常见中文记谱和 ICCS 坐标。
- 五子棋：13/15/19 路自由规则或标准五连；15 路连珠禁手；可独立启用 Swap2 平衡开局。
- 井字棋：3×3 完整规则。
- 黑白棋：完整夹子、自动跳过无子可下的一方和终局计子。

## 安装

在 AstrBot WebUI 的插件管理中上传本插件 ZIP。新版要求 AstrBot `>=4.9.2,<5`，依赖会通过 `requirements.txt` 安装。

若从旧版覆盖升级，建议先在旧棋局结束后再更新。旧版把战绩写在插件目录内，新版按官方规范使用插件 KV 存储，因此旧战绩不会自动导入。

## 快速上手

```text
/开局 国际象棋 黑方
/开局 围棋          # 默认标准 19 路
/开局 围棋 13路     # 也可选 9 路或 13 路
/开局 中国象棋
/开局 五子棋 自由 15路
/开局 五子棋 标准 15路
/开局 五子棋 连珠
/开局 五子棋 连珠 Swap2
/开局 井字棋
/开局 黑白棋
/加入棋局
```

轮到自己时，可以任选一种写法：

```text
/下棋 Nc3
/Nc3
Nc3
/b1c3
/b1 c3
b1 c3
```

裸走法只在以下条件全部满足时触发：本群已有棋局、发送者是本局选手、正轮到该玩家、文本看起来像该棋种走法。其余管理指令仍必须带 `/`。

各棋种示例：

```text
国际象棋  Nc3 / b1c3 / O-O
围棋      D4 / pass（字母坐标跳过 I）
中国象棋  炮二平五 / h2e2 / h2 e2
五子棋    H8
井字棋    5 / B2
黑白棋    D3
```

## 对局指令

```text
/棋盘              重新发送纯图片棋盘
/棋谱              查看当前文字棋谱
/悔棋              发起悔棋请求
/同意悔棋 /拒绝悔棋
/和棋              发起和棋提议
/同意和棋 /拒绝和棋
/流局              等待阶段取消；对弈中请求无战绩结束
/同意流局 /拒绝流局
/强制流局          管理员清理卡住的棋局
/认输
/强制胜利          对手超时且正轮到对手时可用
/AI分析            申请一次本地轻量分析
/势力范围          围棋势力图（同样需要对手同意）
/同意AI /拒绝AI
/选白 /选黑 /交换 /加两子   Swap2 开局阶段使用
/战绩
/棋类帮助
```

凡是发送棋盘图片的响应，消息链里只有图片组件；终局结果会作为下一条独立文字消息发送。棋盘用橙色标记上一步起点、绿色标记终点（落子类游戏只有终点）。

## 局势分析

`/AI分析` 每次都需要对手明确同意。所有六个棋种都会返回双方胜率与下一步推荐，不只支持国际象棋：

- 国际象棋、中国象棋：一层子力、机动性与将军启发式搜索。
- 围棋：轻量势力/面积估算、胜率、推荐着点，并追加一条独立的纯图片势力范围图；`/势力范围` 是同一分析请求的别名。
- 五子棋：按本局所选规则检查一步制胜、迫近成五和攻防热点。
- 井字棋：完整极小化极大搜索。
- 黑白棋：角、边、翻子数和当前子数的启发式评估。

分析完全在本地运行，不调用 LLM，也不产生模型费用；它适合娱乐提示，不等同于 Stockfish、KataGo 等专业引擎。围棋势力图是估算图，并不自动完成复杂死活判断。

## 五子棋规则

规则与开局平衡可以分别选择：

```text
/开局 五子棋 自由            # 五子或以上即胜，无禁手
/开局 五子棋 标准            # 必须恰好五子，长连不算胜也不算犯规
/开局 五子棋 连珠            # 15路；黑方禁长连、四四和三三，白方五子或以上胜
/开局 五子棋 自由 Swap2      # 无禁手 + 国际 Gomoku 常用平衡开局
/开局 五子棋 连珠 Swap2      # 连珠禁手 + Swap2，可自由组合
```

Swap2 流程：开局者连续摆黑、白、黑三子；后加入者使用 `/选白`、`/交换` 或 `/加两子`。若选择加两子，则再连续摆白、黑两子，最后由开局者使用 `/选黑` 或 `/选白`。选色导致的换边由插件自动完成，之后白方正常行棋。

## 已知边界

- 围棋终局采用简化面积数子，不自动识别死子；正式对局应先自行提净死子。
- 中国象棋中文记谱支持常见的“炮二平五”形式；同路同名棋子需要区分前后时，请使用无歧义坐标记谱。
- 连珠禁手按 RIF 定义检测长连、四四、三三，并对常见“假三”进行递归合法性排除；极端复合题型仍建议以正式裁判结论为准。
- 活跃棋局和战绩使用 AstrBot 插件 KV 存储。更新/重载不会把数据写回插件目录。

## 目录

```text
main.py                    AstrBot 事件与指令适配
boardgames/session.py      房间、玩家和并发锁
boardgames/*_engine.py     各棋种规则
boardgames/render.py       统一图片渲染
_conf_schema.json          WebUI 配置
tests/                     不依赖 AstrBot 的规则回归测试
```

开发接口依据 [AstrBot 官方插件开发文档](https://docs.astrbot.app/dev/star/plugin-new.html)；持久化使用官方插件 KV，图片通过单图片消息链发送。连珠禁手依据 [RIF 国际连珠规则](https://www.renju.net/rifrules/)，Swap2 流程依据 [RIF/RenjuNet 的 Gomoku Swap2 规则](https://www.renju.net/rule/11/)。
