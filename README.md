# AstrBot 多棋盘对弈插件

在一个群聊中提供国际象棋、围棋、中国象棋、五子棋、井字棋和黑白棋，并统一处理房间、选边、棋钟、图片棋盘、战绩、等级分和轻量局势分析。

## 简介

- 六种棋类，共用一套自然的开局和对局流程。
- 轮到自己时可以直接发送走法；管理指令仍然保留 `/`。
- 棋盘自动朝向当前行棋方，井字棋保持固定视角。
- 图片显示双方、棋钟、四边坐标和上一步落点；终局图包含棋盘和结算卡。
- 支持自定义比赛用时、分级提醒、悔棋、和棋、认输和流局。
- 保存分棋种战绩、最近对局和 Elo 等级分，并可查看排行榜。
- `/AI分析` 经对手同意后给出娱乐性质的胜率与推荐走法；围棋还能显示势力范围图。

## 快速开始

### 1. 开房

```text
/开局 国际象棋
/开局 围棋
/开局 中国象棋
/开局 五子棋
/开局 井字棋
/开局 黑白棋
```

开房时可以追加规则、棋盘大小和计时：

```text
/开局 国际象棋 计时=30+0
/开局 围棋 19路 计时=60|3x30
/开局 围棋 13路
/开局 围棋 9路 不计时
/开局 五子棋 自由 19路
/开局 五子棋 标准 15路
/开局 五子棋 连珠 Swap2
```

### 2. 加入并选边

```text
/加入棋局
/选先
/选后
```

也可以按棋种使用 `/选黑`、`/选白`、`/选红`。普通对局中一人选定后，另一人自动获得剩余一方；五子棋 Swap2 使用自己的选色流程。

开赛时会依次发送对阵卡、棋盘和计时提示。对阵卡包括头像、等级分、总战绩、该棋种战绩、双方交手记录、规则和用时。

### 3. 行棋

国际象棋支持以下全部写法：

```text
/下棋 Nc3
/Nc3
Nc3
/b1c3
/b1 c3
b1 c3
```

其他棋种示例：

```text
国际象棋  Nc3 / Nxf7+ / O-O / b1c3
围棋      D4 / pass                 坐标字母跳过 I
中国象棋  炮二平五 / 马八进七 / h2e2
五子棋    H8
井字棋    5 / B2                    数字从左上到右下固定为 1～9
黑白棋    D3
```

裸走法只会在本群存在棋局、发送者是选手、正轮到该玩家且文本像合法走法时接管。认输、悔棋、AI 分析等非走子指令仍必须带 `/`。

## 等级分原理

排行榜使用每个棋种独立计算的 Elo 等级分。新玩家在每个棋种都是 1000 分，国际象棋分不会影响围棋分。

插件使用固定 `K=32`：

```text
预期得分 E = 1 / (1 + 10 ^ ((对手分 - 自己分) / 400))
实际得分 S = 胜 1、和 0.5、负 0
等级分变化 = round(32 × (S - E))
```

理论变化量在双方之间相反；实际写入时每人的等级分最低为 100，因此触及下限后不一定严格零和。例子：

- 1000 对 1000：胜者约 `+16`，负者 `-16`；和棋双方不变。
- 1200 对 1000：强方正常获胜约 `+8`；弱方爆冷获胜约 `+24`。
- 高分方与低分方和棋时，高分方会掉分，低分方会涨分。

规则终局、认输、棋钟超时和双方同意的和棋都会计入；流局不计。Elo 表示历史赛果，不是 `/AI分析` 显示的当前局面胜率。

`/对局记录` 中显示的普通胜率采用“胜局数 ÷ 总局数”，和棋会计入总局数但不会折算成半个胜局。这一百分比也不是 Elo 公式里的预期得分。

## 围棋终局计分

双方连续 `pass` 后，插件按简化的中国规则面积法终局：

```text
黑方得分 = 棋盘上的黑子 + 只被黑方包围的空点
白方得分 = 棋盘上的白子 + 只被白方包围的空点 + 贴目
```

默认白贴 6.5 目，可在插件配置中修改。被双方共同接触的空点不归任何一方，提掉的棋子不再单独重复计分。两边最终分数完全相等才是和棋。

自动数子不会判断复杂死活和争议死子，因此结束前应先把确认的死子提净。局中 `/AI分析` 给出的目数、胜率和势力图只是低开销估算，不会参与正式终局判定。

## 比赛棋钟

选边完成后棋钟启动，耗尽自动判负，并显示在棋盘图顶部。支持：

```text
15+10       每方 15 分钟，每步加 10 秒
10          每方 10 分钟包干
60|3x30     每方 60 分钟，之后 3 次 30 秒读秒
不计时      关闭本局棋钟
```

默认值：

| 棋种 | 默认用时 |
| --- | --- |
| 国际象棋 | `15+10` |
| 围棋 | `60|3x30` |
| 中国象棋 | `10+5` |
| 五子棋 | `20+3` |
| 井字棋 | `2+2` |
| 黑白棋 | `10` |

默认提醒：全程每分钟；3 分钟内每 30 秒；2 分钟内每 15 秒；1 分钟内每 10 秒；30 秒内每 5 秒。管理员可以在 WebUI 中逐棋种修改默认棋钟，也可以修改提醒档位。

## 六种棋类详细说明

### 国际象棋

完整规则由 `python-chess` 提供，支持 SAN 和 UCI，包含王车易位、吃过路兵、升变、将军、将死、逼和与规则和棋。

### 围棋

支持 9×9、13×13 和标准 19×19；包括提子、禁入点、全局同形、停一手和面积数子。坐标跳过字母 I。

### 中国象棋

支持常见中文记谱和 ICCS 坐标，包括蹩马腿、塞象眼、炮架、九宫、将帅照面、将军和送将校验。同路同名棋子无法用中文记谱明确区分时，建议使用坐标。

### 五子棋

- 自由规则：五子或以上即胜，无禁手。
- 标准规则：必须恰好五子；长连不胜，也不算犯规。
- 连珠规则：固定 15 路；黑方禁止长连、四四和三三，白方五子或以上获胜。
- Swap2：可以与自由或连珠规则组合，用来降低先手优势。

Swap2 中，开局者先摆黑、白、黑三子；另一人选择 `/选白`、`/交换` 或 `/加两子`。若加两子，则再摆白、黑，最后由开局者 `/选黑` 或 `/选白`。

### 井字棋

固定 3×3 和固定视角。数字 1～9 始终从左上到右下排列，也支持 A1～C3。横、竖或斜线三子连成即胜。

### 黑白棋

完整夹子与翻子规则。无合法着法时自动跳过；双方都无合法着法或棋盘填满后，棋子较多者获胜。

## 局势分析的范围

所有棋种都会给出双方胜率和推荐走法，但分析强度定位为群聊娱乐：

- 国际象棋、中国象棋：一层子力、机动性和将军启发式。
- 围棋：距离衰减势力、面积估算和候选落点，并生成势力范围图。
- 五子棋：一步制胜、成五威胁和攻防热点。
- 井字棋：完整极小化极大搜索。
- 黑白棋：角、边、行动力与子数启发式。

它们不等同于 Stockfish、KataGo 等专业引擎，也不应作为正式裁判依据。

## 已知边界

- 围棋不会自动判断复杂死活；正式终局前应先处理争议死子。
- 中国象棋复杂的前后同名子中文记谱可能有歧义，此时使用坐标。
- 连珠禁手实现覆盖长连、四四、三三和常见假三排除；极端题型以正式裁判结论为准。
- 轻量 AI 分析追求响应速度，不保证最优着法或专业胜率精度。
- 头像获取取决于消息平台是否提供公开头像地址，失败时使用昵称首字占位。

## 项目结构

```text

boardgames/session.py      房间、玩家和并发锁

boardgames/clock.py        加秒、包干、读秒和提醒
boardgames/*_engine.py     六种棋类规则与轻量分析
boardgames/render.py       棋盘、对阵卡和终局卡渲染

```
